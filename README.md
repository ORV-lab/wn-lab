# WN-Lab

`WN-Lab` — это desktop-first веб-проект для чтения, каталогизации и управления
переведенными веб-новеллами и связанными произведениями.

Сейчас репозиторий содержит фронтенд-прототип, собранный по макетам из Figma,
и каркас backend-части на `FastAPI`, подготовленный для дальнейшей интеграции.

## Текущее состояние

Проект находится в активной сборке продукта.

Что уже есть в репозитории:

- Многостраничный frontend на `Next.js + TypeScript`
- Стартовый backend на `FastAPI`
- Общий layout, навигация, footer и система иконок
- Основные сценарии чтения и пользовательские экраны
- Документ с API-контрактом для будущей связки frontend и backend

Что еще не завершено:

- Живая интеграция данных между frontend и backend
- Реальная авторизация и хранение пользовательских данных
- Production-ready backend-логика
- Финализированный сценарий ИИ-перевода

## ИИ-перевод

`ИИ-перевод` является частью продуктового направления и уже имеет собственный
интерфейс во frontend.

На данный момент этот раздел находится в разработке. В репозитории уже есть
продуктовая поверхность и общая структура приложения, но финальные детали
реализации пока намеренно не зафиксированы.

## Технологический стек

Frontend:

- `Next.js 15`
- `React 19`
- `TypeScript`
- App Router

Backend:

- `FastAPI`
- `Uvicorn`
- `Python 3.11+`

## Структура репозитория

```text
WN-Lab/
├─ frontend/   Next.js приложение
├─ backend/    FastAPI сервис
└─ README.md
```

Если чуть конкретнее:

- `frontend/src/app` содержит entry point'ы маршрутов
- `frontend/src/components` содержит page shell'ы и общий UI
- `frontend/src/data` содержит временные mock-данные frontend-части
- `backend/app/main.py` содержит точку входа FastAPI-приложения
- `backend/app/api/routes` содержит backend-роуты
- `backend/API_CONTRACT.md` описывает планируемую API-поверхность

## Быстрый старт

### Frontend

Установка зависимостей:

```bash
cd frontend
npm install
```

Запуск dev-сервера:

```bash
npm run dev
```

### Backend

Установите зависимости backend-части в удобное Python-окружение, затем
запустите:

```bash
cd backend
uvicorn app.main:app --reload
```

Локальные адреса по умолчанию:

- Frontend: `http://localhost:3000`
- Backend: `http://localhost:8000`
- Health-check: `http://localhost:8000/health`

## Состояние UI и дизайна

Frontend собирается на основе Figma-макетов проекта и сейчас развивается
экран за экраном.

Кодовая база уже включает:

- Общий визуальный shell приложения
- Собственную систему иконок
- Переиспользуемые header и footer

Часть экранов пока использует mock-данные и статические заглушки, пока backend
API только подготавливается.
